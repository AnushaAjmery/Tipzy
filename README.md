# Tipzy – Custom Press-On Nails (Karachi, Pakistan)
**Made-to-order press-on nails, sized in mm to each customer, delivered across Pakistan.**

> Brand: **Tipzy** | Folder: `tipzy_press_on_nails/`
> Live Demo: `https://AnushaAjmery.github.io/tipzy_press_on_nails/`

## Business idea
Made-to-order press-on nails, sized in mm to each customer, delivered across Pakistan.

## Prices
Classic Rs 1,500 · Designer Rs 2,200 · Premium 3D/Bridal Rs 3,200 · Application Kit Rs 250. Delivery Rs 200, free above Rs 3,000.

## Financial estimates (monthly)
Startup Rs 75,000 · Sales Rs 134,500 · Expenses Rs 84,050 · Profit Rs 50,450 (37.5%) · Break-even about Rs 59,000 · Payback about 1.5 months.

## Features

- **Home Page** - Hero slider, best sellers, testimonials
- **Shop Page** - Product gallery with filter, comparison table
- **Order Page** - Form with live total calculation + WhatsApp order
- **Business Plan Page** - Startup cost, funding progress bar
- **Calculator Page** - Live profit, break-even & payback calculator with reset
- **Fully Responsive** - Works on mobile, tablet & laptop
- **No Backend Needed** - Pure HTML, CSS & JavaScript

## Run
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
Edit `CONFIG` at the top of `script.js` to set your real WhatsApp number (format 923xxxxxxxxx), Instagram and email.
